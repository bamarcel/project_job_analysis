# 💼 Data Jobs Insights — Trouver les compétences qui paient le plus 💰

Bienvenue sur ce mini-projet SQL où je plonge dans un dataset d’offres d’emploi liées aux métiers de la data (Data Analyst, Data Scientist, etc.).
L’objectif ? 🕵️‍♂️ Explorer, analyser et comprendre le marché de la data à travers des requêtes SQL concrètes.

## 🎯 Objectif du projet

1. Identifier les offres les mieux payées dans le domaine de la data, dans mon cas des Data Analyst.

2. Déterminer les compétences (skills) les plus souvent demandées par ces offres.

3. Faire le croisement entre salaire et popularité des skills pour repérer les plus rentables à maîtriser 💡

## 🧰 Stack technique

- **PostgreSQL** pour les requêtes et l’analyse.

- **SQL pur** (CTE, agrégations, jointures, sous-requêtes).

- **Dataset** : offres d’emploi du secteur data 🧑‍💻
